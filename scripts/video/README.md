# Submission video, deck and cover — built from code

Everything in `submission/` is generated by these scripts against the running app
(`npm start`, http://localhost:3000). Run them from one working folder.

| Step | Script | Output |
| --- | --- | --- |
| Record a real demo run | `node record.mjs rec 1` | timestamped frames + audio/caption log |
| Render title & explainer cards | `node cards.mjs` | `cards/*.png` (1920×1080) |
| Narrator voice-over | `.venv/bin/python vo.py` | `vo/*.wav` (Kokoro `am_michael`) |
| Caption / speaker-chip / frame overlays | `node overlays.mjs rec` | `ov/*.png` |
| Assemble the MP4 | `.venv/bin/python build.py rec` | `read-along-coach-demo.mp4` |
| Slide deck | `node deck.mjs` | `read-along-coach-deck.pdf` |

Needs `puppeteer-core` (npm) with the system Chrome, and `imageio-ffmpeg` (pip,
bundles ffmpeg) in `.venv`.

How it stays honest: the demo segment is the real app, captured frame by frame.
Its captions are driven by the app's own state changes (pill tone, word classes),
not by a script of times, and the in-app audio is rebuilt from a log of every
clip the page actually played, placed at the moment it played.

The demo is captured at a true 2x (device scale forced at browser level; an
emulated scale still yields CSS-pixel screencast frames), framed on the ink
background, and cut from a wide shot to a close-up of the reading surface. A
band under the window carries the captions and a "Reader" / "Coach" chip that
is lit exactly while that voice is playing. Work in a folder outside `/tmp`
(e.g. `.videowork/`, gitignored): a reboot wipes `/tmp` mid-build.
